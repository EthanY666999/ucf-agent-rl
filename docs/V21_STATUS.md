# UCF v2 与 v2.1 的发布边界

- `code/ucf/ucf_collect.py` 是 S05 当前的 v2 算法实现。
- `code/ucf/ucf_first_fence.py`、`first_fence.py` 是隔离开发的 v2.1 源码，节点在本回合第一个围栏之后，保留原始采样 token 前缀，Part B 仅从动作 token 开始。
- v2.1 **实验性且验收失败，禁止正式训练**。本发布 `train.py` 和统一入口均拒绝 v2.1 正式启动；不存在静默退回 v2 的行为。代码保留供审查和 CPU 合同测试，不附伪造的放行收据。

## 2026-11-09 隔离验收实际结果

F02 全量400步离线回放，共102400条原始轨迹、334426回合。322741回合包含围栏，322721回合还有后继预算；可恢复的回合覆盖约96.50%。这不是GPU实测分叉数。

第一围栏后 token 对应动作与现行最后围栏解析器不一致41328/322741，约12.8053%，超过2%门槛。

分层无偏性模拟中，只有四动作支持集的例子通过（max |z|=1.484）；加入残余质量p[0]=0.08后失败（max |z|=149.442）。Monte Carlo 与该有偏估计器的解析期望一致（max |z|=1.931），因此不能把问题归因于采样噪声。聚合收据见 `data/evidence/v21_math_audit.json`。这是合成反例，不是对实际实验梯度偏差大小的估计。

当前反事实支持集只含有效动作 token；HT 的1/ρ只校正选点，不能补齐未采样的残余支持集。完整概率分解如何修订需要另一个明确方法版本；本发布不擅自去掉p[0]、改解析器、改β/ρ_min/F或放宽阈值。

S05和已完成SFT实验仍按原v2解释。无SFT-v2.1与SFT-v2同时改变初始化及实现，不是严格单变量SFT消融；也不承诺新旧代码在SFT样本上逐位等价。
