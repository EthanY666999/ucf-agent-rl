# 来源与版本边界

本发布是独立研究代码发行，不是旧仓库的镜像。2026-11-09修订仅更新4B计划、依赖与方法门禁；旧UCF仅供历史审计，v2.2／v2.2-ff等待2B验收和源码同步。当前生产 2B 源码基准提交为 `e32ac58b8a857eb98023ec1f79bbe0cf855c95ac`。复制来源为正在执行 S05 的同一生产源码树，仅只读获取；运行中的队列、源码、配置和进程均不因本发布改变。

## 生产来源与发布适配分开记录

- `data/evidence/summary.json` 的 `production_source_hashes` 是复制时实际文件内容的 SHA256；不是只相信 Git HEAD。
- 发布包中的模型路径、数据相对路径、CPU验收入口、独立版本开关等便携改动由本仓库提交记录和发布清单描述。不能再把这些变更后的文件冒充原生产文件哈希。
- v2 保留当前生产的算法定义。v2.1 来源于独立隔离实现，未改动正在执行的S05源码；2026-11-09总体CPU验收失败，GPU admission关闭。功能测试通过不能覆盖首动作/最终解析不一致及残余支持无偏性模拟失败；本发布不绕过这些门禁。
- vLLM补丁是运行库别名修复，生产收据记录改前/改后文件哈希以及57项CPU交换检查。该补丁不变更实验配置。具体安装以 [INSTALL.md](INSTALL.md) 为准。
- 发布不携带任何0.5B训练代码、旧失败实现、权重、checkpoint、rollouts或内部原始日志。历史结果在这里只保留小型聚合表，用于说明研究动机和局限。

## 实验数据与结果

- 冻结任务、地图、演示、评估集必须由发布清单核验 SHA256，克隆后不能现场按seed重新生成另一套地图代替。
- Sokoban S02的1000条专家演示与之后的S03/S04/S05起点相同；RL各臂独立从同一SFT导出模型开始，不能顺接上一个RL模型。
- 难版FrozenLake的1000条Golden Trace继续保留，但不再作为4B默认SFT输入。2B当前从原版F03起步；4B-07及其依赖项待H01结果后统一决定SFT数据和协议，不能直接复用2B模型权重。
- ALFWorld训练任务来自官方冻结train划分，专家不是LLM教师。`data/alfworld/golden/verification.json`记录1000个不同任务fresh-environment完整回放通过；完整轨迹文件1000行，history=2的逐步独立SFT文件15857行（独立计数核对，1000个episode_id）。batch16、1epoch、保留尾批对应992个更新，不能沿用网格SFT的63步。数据/CPU原语完成与ALFWorld完整SFT/RL训练适配未完成分别报告。
- `summary.json` 存放本次读取的原记录文件名、SHA256、聚合数值和明确采集时刻。S05的 `train_metrics.jsonl` 哈希对应截至78步读取的字节快照，后续追加会使服务器当前哈希变化；这不意味着历史快照被篡改。
- 0.5B来源为归档 `ucf_seed44/report_at_completion.json` 及更早的CPU比较汇总。引用它们的聚合结果，不声称本发布重新训练或重新评测了0.5B。实际无SFT/多种子缺失项如实保留。
- F02资格统计是已有GRPO轨迹的离线诊断，不是UCF训练结果。v2抽取10步的格式过滤统计与v2.1全400文件的首围栏审计采用不同候选规则/分母，分别保留，不能直接相减当作实际收益。原模型训练、数据集合与实现版本都不同，不能将其数值直接替代S15结果。
- v2.1隔离审计来源为`q35_ucf_v21_20261109.md`，SHA256为`1ec6ed88241813f9b7c6c1321bd4e593cbf12a8d77dcc4f7643418358d1cc522`。本包仅保留聚合发现及数学/功能测试收据，不携带该内部报告或原始日志。其S05选点回放使用已记录特征输入，并未假装复原历史全词表概率。
